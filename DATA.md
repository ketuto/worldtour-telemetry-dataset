# Data source

`dataset.csv`, `dataset.json`, `dataset.jsonl` and `datapackage.json` in this repository are **not
edited here**. They are generated by the catalogue at
[theaerodrop.com/dataset.csv](https://theaerodrop.com/dataset.csv) on every request, using the same
physics module that renders each bicycle's page, so the numbers cannot drift from the site.

A scheduled workflow (`.github/workflows/sync.yml`) pulls them every Monday at 06:00 UTC and commits
only when something changed. Running it by hand is also fine:

```
curl -fsSL https://theaerodrop.com/dataset.csv -o dataset.csv
```

The page that explains the methodology, and that Google Dataset Search reads, is
<https://theaerodrop.com/dataset>.

## Formats

| File | Format | Contents |
| :--- | :--- | :--- |
| `dataset.csv` | CSV | One row per bicycle, nine columns, empty cells where a value does not exist |
| `dataset.json` | JSON | Every published product, with geometry per size and the protocol constants |
| `dataset.jsonl` | NDJSON | The same objects, one per line, for streaming ingest |
| `datapackage.json` | Frictionless | Column types, units and licence, readable by open-data portals |

## If you fork this

Prices and availability change. If you need the current figures, read them from the source rather
than from your fork; a two-month-old copy of a price is worse than no price at all.
